🔍 常见问题排查 (FAQ)

问题现象 可能原因 解决方案
动画未显示 / 样式错乱 缓存未清除或路径错误 1. 务必执行 hexo clean。
2. 检查 _config.yml 中 theme 名称是否与文件夹完全一致。
3. 浏览器硬刷新 (Ctrl+F5)。
GitHub Pages 404 部署分支错误或构建中 1. 检查仓库 Settings -> Pages，确认 Source 分支与部署命令中的 branch 一致。
2. 等待 1-2 分钟让 GitHub 完成构建。
3. 确认推送的文件在仓库根目录，而非子文件夹。
图标不显示 字体文件或 SVG 路径错误 检查主题 source 目录下的字体 / 图标文件是否完整，以及 CSS 中的引用路径是否正确。
蓝色背景不生效 CSS 变量未加载 检查浏览器控制台 (F12) 是否有 CSS 加载报错 (404)。确认主题是否正确引用了自定义的 CSS 文件。
推送权限被拒绝 SSH Key 未配置或账号错误 1. 检查使用的 URL 是 SSH (git@...) 还是 HTTPS (https://...)。
2. 若是 SSH，确保本地已添加公钥到 GitHub。
3. 若是 HTTPS，确保账号密码 / Token 正确。

💡 进阶优化建议

  • 自定义动画参数：若要调整动画速度、颜色深浅或粒子数量，请直接编辑主题目录下的 source/js/main.js (或类似文件名) 和 source/css/style.css。
  • SEO 优化：在 _config.yml 中完善 description, keywords 等信息，提升搜索引擎收录。
  • 性能优化：如果动画过于复杂导致加载慢，考虑对大型 JS/CSS 文件进行压缩，或使用 CDN 加速静态资源。
